Un minuto. Los materiales del equipo, en dos repositorios. El repositorio de la réplica, con el pull request número 4, que reúne los cambios de la réplica completa: los guiones, los CSV, las tablas, las 20 figuras y los dos documentos principales. El repositorio de guías, con explicaciones técnicas y para principiantes de cada rival y cada experimento, y la carpeta podcast_notebooklm, con 14 episodios preparados para generar un podcast en NotebookLM a partir de EXPLICACION.md y DEFENSA.md. Un aviso: las guías se escribieron antes de la réplica y en algunos puntos la contradicen, por ejemplo sobre Folly. Si algo no coincide, manda EXPLICACION.md. Y una lista útil para el turno de preguntas: las seis figuras que DEFENSA.md recomienda tener a mano. fig5_paper_frente_a_replica, para Folly; afinidad_dosis_respuesta, para la simulación; docker_frente_a_nativo_oficial, para Docker; memoria_ram, para el techo; nativo_alineado_fig5, para la compartición falsa; y topologia, para el mapa de latencias. Tenerlas abiertas en otra pestaña ahorra mucho tiempo.
